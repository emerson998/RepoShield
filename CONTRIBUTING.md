# Contribuindo

Use Python 3.11+ e Node 22+. Instale `pip install -e './backend[dev]'` e execute
`pytest backend/tests -q`. Para a interface, use `npm ci` e `npm run build` em frontend.

Abra uma issue com cenário, comportamento esperado e passos para reproduzir.
Para novas regras, inclua casos positivos, negativos e os limites conhecidos.
Não use credenciais reais nos testes e não execute o código do projeto analisado.
Não inclua vulnerabilidades sensíveis em issues públicas; consulte SECURITY.md.
